# studio-finder（東京都内の撮影スタジオ空き状況チェッカー）

撮影したい日と時間を入れると、登録したスタジオの中から条件に合うものを一覧にします。
スタジオが公開カレンダー（iCal形式のURL）を出していれば、その時間が空いているかも自動で判定します。

自分用の調査ツールです。追加のインストールは要りません。Python 3.9以降があれば動きます（ターミナルで `python3 --version` と打つと確認できます）。

## 使い方

```bash
cd studio-finder
python3 studio_finder.py --date 2026-10-20 --start 10:00 --end 14:00
```

条件で絞り込む例です。

```bash
python3 studio_finder.py --date 2026-10-20 --start 10:00 --end 14:00 \
  --area 渋谷区 --max-price 6000 --people 5 --html result.html --open
```

| オプション | 意味 |
| --- | --- |
| `--area` | 区市町村（例: 渋谷区） |
| `--station` | 最寄り駅（例: 恵比寿） |
| `--max-price` | 1時間あたりの上限（円） |
| `--people` | 利用人数。定員がこれより少ないスタジオを外す |
| `--html` | 結果を表形式のHTMLで保存 |
| `--open` | 保存したHTMLをブラウザで開く |

結果は「空き → 要確認 → 取得失敗 → 埋まり」の順に、同じ状況の中では概算料金の安い順で並びます。

## 状況の見方

- **空き**：公開カレンダー上で、その時間に予約が入っていない
- **埋まり**：時間が重なる予約がある（重なった時間帯も表示）
- **要確認**：公開カレンダーが登録されていない。予約ページで確認する
- **取得失敗**：カレンダーURLが読めなかった（URL間違い・通信エラーなど）

「空き」でも予約が確定したわけではありません。カレンダーの更新が遅れているスタジオもあるので、最後は必ず予約ページで確かめてください。

## スタジオの登録（studios.csv）

ExcelやNumbersで開いて編集できます。保存は「CSV UTF-8」形式にしてください。

| 列 | 内容 |
| --- | --- |
| name | スタジオ名 |
| area | 区市町村 |
| station | 最寄り駅 |
| price_per_hour | 1時間あたりの料金（円・税込で統一がおすすめ） |
| min_hours | 最低利用時間。概算料金はこれ未満でもこの時間分で計算 |
| capacity | 定員（不明なら空欄） |
| booking_url | 予約ページのURL |
| ical_url | 公開カレンダー（.ics）のURL。なければ空欄 |
| memo | 自由メモ（白ホリ、自然光、機材など） |

いま入っている3件は動作確認用の**架空データ**です。実際のスタジオに置き換えてください。

### 公開カレンダーのURLはどこにある？

スタジオによっては、Googleカレンダーで空き状況を公開しています。
公開ページに埋め込まれたGoogleカレンダーなら、`https://calendar.google.com/calendar/ical/（カレンダーID）/public/basic.ics` の形でiCal URLを取れることがあります。
見つからない場合は空欄のままで大丈夫です。「要確認」として予約ページへのリンクが出ます。

## やっていないこと

インスタベースやスペースマーケットなど、予約サイトのページを自動で読み取る処理（スクレイピング）は入れていません。
各サイトの利用規約で自動取得が認められているか、まだ確認できていないためです。
規約で問題ないと確認できたら、そのサイト専用の読み取り処理を追加できます。
